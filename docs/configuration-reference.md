# API configuration reference

Generated by `make settings-reference`; check with `make settings-reference-check`.
Do not edit the tables by hand. Values come from field declarations, never the
operator's environment or `.env`. Credential-bearing defaults are redacted.

The API loads all capabilities once through `axis_api.config.Settings`.
Python field names and `AXIS_*` aliases remain flat; there are no nested env keys.
Precedence: constructor arguments, process environment, package-local `.env`,
file secrets, then defaults. Unknown keys are ignored. Lists use JSON arrays.
The root Make commands load the selected root env file as described in
[development](development.md). This reference covers the API facade; the worker
and SDK retain their own configuration and must be configured separately.

See [configuration validation](configuration.md) for production combinations,
ownership and compatibility evidence, and [deployment](deployment.md) for
operational profiles and secret injection.
